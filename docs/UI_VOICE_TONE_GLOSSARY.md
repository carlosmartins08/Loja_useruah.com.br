# UI Voice Tone Glossary

Data de revisao: 2026-05-30

## Termos oficiais
- Carrinho: `Carrinho`
- Pedido: `Pedido`
- Status do pedido: `Status do pedido`
- Ajuda: `Central de ajuda`
- Checkout: `Finalizacao do pedido`

## Verbos preferidos para CTA
- `Continuar`
- `Finalizar pedido`
- `Adicionar ao carrinho`
- `Ver detalhes`
- `Acompanhar pedido`

## Evitar
- `Clique aqui`
- `Comprar agora` sem contexto
- `Erro inesperado` sem acao recomendada

## Padrao de mensagem de erro
- Titulo curto
- Causa em linguagem humana
- Acao recomendada imediata
