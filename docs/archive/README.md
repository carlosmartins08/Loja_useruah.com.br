# Archive de Documentos

Este diretório guarda documentos retirados da camada ativa de operação.

Critério de arquivamento aplicado:
- histórico datado que não é fonte viva de execução;
- plano de transição já concluído/superado;
- template redundante sem uso no fluxo atual.

Se algum arquivo daqui voltar a ser referência operacional, ele deve retornar para `docs/` e ter links atualizados.
