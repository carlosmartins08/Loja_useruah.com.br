# Use Ruah - Sistema de Cores v2

Arquivos gerados:
- `brand-colors.v2.json`: tokens institucionais da marca.
- `print-colors.v2.json`: cores permitidas para estampas.
- `product-colors.v2.json`: cores comerciais de produto, fases, fornecedor, contraste e `allowedPrints`.
- `color-system.v2.json`: indice consolidado para integracao.

Principais melhorias:
- `displayName` com acentuacao para interface.
- `name` tecnico sem acento para compatibilidade.
- `brandToken` conectando cor comercial ao token institucional.
- `allowedPrints` por cor de produto.
- `supplierValidated` para controle de producao.
- `textColorSmall` para legibilidade em componentes pequenos.
- `mockupPathTemplate` para integracao com mockups do site.
